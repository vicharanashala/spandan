# 📦 Spandan Release Assets

This folder contains the 3 official 1-Click setup installers for **Spandan**, ready for deployment to [GitHub Releases](https://github.com/Bhimashri-Deka/spandan/releases).

---

## 🚀 The 3 Platform Release Assets

| Platform | File | Size | Description |
| :--- | :--- | :--- | :--- |
| 🪟 **Windows** | **`Spandan_Windows_Setup.exe`** | **17.9 KB** | 1-Click installer for Windows (installs app, creates Desktop shortcut & starts Spandan) |
| 🍎 **macOS** | **`Spandan_macOS_arm64.dmg`** | **829 KB** | Apple Silicon (M1/M2/M3/M4) Disk Image containing `Spandan.app` (Drag to Applications) |
| 🐧 **Linux** | **`spandan_1.0.0_amd64.deb`** | **391 KB** | Debian/Ubuntu `.deb` system package with `/opt/spandan` and desktop launcher |

---

## 📥 How to Upload to GitHub Releases
1. Go to **https://github.com/Bhimashri-Deka/spandan/releases/new**
2. Tag: `v1.0.0`
3. Drag and drop these 3 files into the release assets area.
4. Click **Publish release**.
