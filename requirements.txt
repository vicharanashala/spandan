# Spandan - Project Requirements

This is a Node.js-based project. Node.js dependencies are defined in `package.json` files and should be installed using `npm`. Below is the list of system requirements and the primary Node.js packages used by this application.

## 1. System Prerequisites
* **Node.js**: v18.x or higher (v20+ recommended)
* **npm**: v9.x or higher (installed automatically with Node.js)
* **MongoDB**: v6.0 or higher (either a local instance running or a MongoDB Atlas URI)

---

## 2. Monorepo Workspaces & Package List
To install all these packages, run `npm run install:all` from the project root.

* **pm2**: ^7.0.1 (Production process manager)

### Frontend Workspace (spandan-frontend)

## 3. Installation & Run Command Quick Reference

### Option A: Automatic Installation (Recommended)
From the root directory, run:
```bash
npm run install:all
```
This script runs `npm install` for the root, frontend, and backend packages in one step.

### Option B: Manual Installation
If you prefer running standard npm commands:
```bash
# Install root tools
npm install

# Install backend workspace packages
npm install --workspace=backend

# Install frontend workspace packages
npm install --workspace=frontend
```

### Running the Project
Once dependencies are installed, copy and configure your backend environment file (`backend/.env.example` -> `backend/.env`), make sure MongoDB is running, and then run:
```bash
npm run dev
```
This starts both the React frontend and Express backend concurrently.
